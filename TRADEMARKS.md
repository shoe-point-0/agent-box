# Name and Trademark Status

“Agent Box,” `abox`, and associated names are working project identifiers. No comprehensive trademark search, legal clearance, registration, or neutral-foundation name review has been completed. The repository therefore makes no claim that these names are available for registration or conflict-free use.

The Apache-2.0 license grants copyright and patent permissions described in [`LICENSE`](LICENSE); it does not grant trademark rights. Do not imply endorsement, certification, or official project status through names or marks.

Before the first public release, maintainers must record a name review covering relevant software-project, package, domain, repository, and trademark registers in intended distribution jurisdictions. Material uncertainty requires qualified legal review or a rename before release. Search results are evidence at a point in time, not a legal guarantee.

Any future trademark policy, logo usage rule, ownership transfer, or foundation name review requires a public governance decision. Until then, forks should use a name that clearly distinguishes them from this project and should not imply that modified builds are official Agent Box releases.
